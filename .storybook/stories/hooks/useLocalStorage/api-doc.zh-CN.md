## API

### 参数

| 参数           | 说明                             | 类型                        | 默认值 |
| -------------- | -------------------------------- | --------------------------- | ------ |
| `key`          | 存储 key；空值/`null` 禁用持久化 | `string \| null`            | -      |
| `initialValue` | 初始值；函数形式只会被求值一次   | `T \| (() => T)`            | -      |
| `options`      | 可选行为配置                     | `UseLocalStorageOptions<T>` | -      |

### 选项 —— UseLocalStorageOptions\<T\>

| 参数          | 说明                              | 类型                   | 默认值           |
| ------------- | --------------------------------- | ---------------------- | ---------------- |
| `sync`        | 监听 `storage` 事件，跨标签页同步 | `boolean`              | `true`           |
| `serialize`   | 自定义序列化函数                  | `(value: T) => string` | `JSON.stringify` |
| `deserialize` | 自定义反序列化函数                | `(raw: string) => T`   | `JSON.parse`     |

### 返回值

| 成员       | 说明                     | 签名                                      |
| ---------- | ------------------------ | ----------------------------------------- |
| `value`    | 当前状态值               | `T`                                       |
| `setValue` | 更新值并写入存储         | `(action: T \| ((prev: T) => T)) => void` |
| `remove`   | 重置为初始值并删除存储项 | `() => void`                              |
