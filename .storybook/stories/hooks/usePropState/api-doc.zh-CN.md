## API

### 参数

| 名称      | 说明            | 类型                     | 默认值 |
| --------- | --------------- | ------------------------ | ------ |
| `value`   | 驱动状态的 prop | `T \| undefined`         | -      |
| `options` | 配置选项        | `UsePropStateOptions<T>` | `{}`   |

### 选项 —— UsePropStateOptions\<T\>

| 名称       | 说明                                                                                                              | 类型                            | 默认值      |
| ---------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------- | ----------- |
| `fallback` | prop 为 `undefined` 时使用的值。它同时也是初始状态，因此支持受控/非受控模式（例如 `open` + `defaultOpen`）        | `T`                             | `undefined` |
| `isEqual`  | 判断 prop 是否变化的自定义相等函数。当 prop 是每次渲染都会新建的对象时，请传入浅比较或深比较                      | `(prev: T, next: T) => boolean` | `Object.is` |
| `enabled`  | 是否允许 prop 驱动内部状态。为 `false` 时仍会记录 prop 变化（以便之后能检测到变化），但不会把 prop 的值写入 state | `boolean`                       | `true`      |

### 返回值

| 成员       | 说明                            | 类型                          |
| ---------- | ------------------------------- | ----------------------------- |
| `state`    | 与 prop 保持同步的内部状态      | `T`                           |
| `setState` | 与 `useState` 相同形状的 setter | `Dispatch<SetStateAction<T>>` |
