## API

### 参数

| 参数    | 说明       | 类型 | 默认值 |
| ------- | ---------- | ---- | ------ |
| `value` | 被包装的值 | `T`  | -      |

| 成员  | 说明                          | 类型                  |
| ----- | ----------------------------- | --------------------- |
