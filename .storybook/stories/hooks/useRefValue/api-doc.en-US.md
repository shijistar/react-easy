## API

### Params

| Name    | Description       | Type | (Default) |
| ------- | ----------------- | ---- | --------- |
| `value` | The wrapped value | `T`  | -         |

### Return

| Member | Description                                          | Type                  |
| ------ | ---------------------------------------------------- | --------------------- |
| `ref`  | A mutable ref object, but the reference is immutable | `MutableRefObject<T>` |
