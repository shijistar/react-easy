## API

### 参数

| 参数 | 说明           | 类型             | 默认值 |
| ---- | -------------- | ---------------- | ------ |
| `fn` | 函数体，需传入 | `T \| undefined` | -      |

### 返回值

| 成员 | 说明                                      | 类型 |
| ---- | ----------------------------------------- | ---- |
| `fn` | 引用不可变的函数；内部始终调用最新的 `fn` | `T`  |

> `T extends (...args: any[]) => any`。
